# ADR 0001：单包 src 布局与目录约定

- 状态：已采纳（2026-10，重构提交 1/8–8/8）
- 背景：诊断内核由仓库根的扁平脚本（engine/ ml/ llm/ kb/ rules/ + 多个入口脚本）
  演进而来，即将服务化（FastAPI 薄封装、MySQL、Web、调度/worker、Docker 离线部署）。

## 决策

采用**单一可安装包 `ai_ops`（src 布局）**，不引入 monorepo/workspace，不引入六边形分层；
服务化真正落地（services/api 出现第一个真实文件）前不预埋空目录。

```
AIOps/
├── pyproject.toml          uv + uv_build；ai-ops 控制台脚本
├── config/*.yaml.example   配置模板；真实 db/llm/kb.yaml 不入库
├── src/ai_ops/             唯一随 wheel 发布的包
│   ├── cli.py              ai-ops 入口（--id/--text/--llm/--fast/--rule）
│   ├── pipeline.py         混合诊断编排 + 决策门（稳定契约 diagnose(record)）
│   ├── reporting.py        纯文本报告（混合 / 纯规则）
│   ├── contract.py         TypedDict 契约（DiagnosisRecord/Result/Evidence/Answer）
│   ├── paths.py / config.py  路径解析与 YAML+环境变量配置
│   ├── rules_store.py / evidence.py
│   ├── engine/             只读 Oracle、解析器、规则引擎、TLOG 取数
│   ├── ml/                 分流器、相似召回、数据集构建、训练
│   ├── kb/  llm/           Dimple 知识适配、OpenAI 兼容客户端与提示词
│   ├── assets/rules/       规则包资产（YAML，随 wheel 打包）
│   └── ops/                常驻自检（doctor / llm_probe / kb_selftest）
├── scripts/                开发/评估/数据脚本（不打包）
├── tests/unit|integration/ pytest
└── var/                    运行时资产（gitignore）：models/ data/ reports/
```

## 约定

1. **稳定契约**：`ai_ops.pipeline.diagnose(record) -> dict` 是未来 FastAPI/调度器/worker
   唯一可依赖的调用面；组件默认每次新建，支持注入复用（router/retriever/eng/kbcli/llm）。
2. **规则双层来源**：包内 `assets/rules` 为基线，`AIOPS_RULES_DIR` 为外挂发布目录。
   合并语义：runbook 同名整体覆盖；errors.yaml 的 types 按 id 合并（同 id 替换且位置不变、
   新 id 追加）；noise_rules 去重追加；外挂缺失时与纯基线完全一致。
3. **路径唯一出口**：`paths.py`，优先级 AIOPS_* 环境变量 > 仓库根 var/ > 容器 /app。
   运行时资产（模型、数据集、报告、KB 快照）落 var/，不入库；镜像构建时 COPY 制品或挂载。
4. **配置**：仓库只跟踪 `*.example`；字段级环境变量覆盖（AIOPS_DB_*、AIOPS_LLM_*、
   AIOPS_KB_*），供 Compose 注入密钥；自检输出不得打印密钥。
5. **脚本三分流**：随产品发布的常驻自检进 `src/ai_ops/ops/`；一次性评估/数据脚本进
   `scripts/`（不打包）；断言进 tests/。
6. **入口**：统一 `uv run ai-ops`；仓库根 hybrid_diagnose.py / diagnose.py 仅为迁移期
   垫片（re-export 既有符号），重构末轮删除。
7. **依赖形态**：fastapi/uvicorn/pymysql 放在 `api` extras，内核不背服务化依赖。

## 后果

- 新克隆即可 `uv sync` + `uv run pytest`；无模型/数据集时召回静默降级为空，规则/ML 快路径
  之外的路径仍可离线运行；LLM/KB 缺失均不阻断主流程。
- wheel 只含代码与规则 YAML，不含配置真实值、数据与模型——满足离线交付与数据不出网要求。
- 代价：开发态须以 `uv run`（或 editable install）运行，根目录 `python xxx.py` 的旧习惯失效。

## 模型/数据集获取

`var/models/*.joblib` 与 `var/data/ml/dataset.csv` 不入库、不进 wheel，二选一：

- 内网制品库/构建期 COPY（交付推荐）；
- 有库环境重训：`uv run python -m ai_ops.ml.dataset` →
  `uv run python -m ai_ops.ml.train_router`（产物自动落 var/）。
